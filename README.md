# 🐶 TinDog

TinDog is a responsive landing page for a fictional mobile app that acts as a "Tinder for dogs." This project was built to practice front-end design, layout structuring, and responsive design techniques using Bootstrap and custom CSS.

## 🚀 Features

* **Fully Responsive Design:** Adapts smoothly to different screen sizes, from mobile devices to desktop displays.
* **Modern Layout Elements:** Features an eye-catching title section, feature highlights, user testimonials, pricing tiers, and a call-to-action footer.
* **Styling Components:** Styled with custom CSS and Bootstrap framework principles.

---

## 🛠️ Built With

* **HTML5:** For structuring the page content.
* **CSS3:** For styling, colors, and layout customization.
* **Bootstrap:** For responsive grids and pre-styled components.
